# PR #212 revised draft

## Title

修复苦痛快感化：仅在苦痛增量为正时转化为心理快感，避免负向变化反向清空心理快感

## Body

## 玩家可见问题

角色处于心控「苦痛快感化」状态时，执行会降低苦痛的指令（如 `[4103]体控-强制高潮`），结算会出现巨额负向心理快感。实测中一次强制高潮直接把心理快感从 lv10 清空到 0（`心理快感 -272586`），而苦痛本身反而没有下降（`苦痛 +3811`）。玩家看到的效果与「苦痛转化为快感」的设计完全相反。

## 原因

`Script/Settle/common_default.py` 的通用状态结算里，苦痛（state 17）在「苦痛快感化」生效时会整体改道为心理快感（state 23）结算，但改道条件没有判断变化量的正负。于是本应减少苦痛的负向增量也被改道，变成了一次巨额负向的心理快感结算。

## 修复

在现有通用状态结算的苦痛改道条件上增加 `final_value > 0` 判断：

- 最终为正的苦痛增量：继续复用原有的 state 23 结算，转化为心理快感；
- 最终为零或负的苦痛变化：留在原有 state 17 路径，正常增减苦痛。
