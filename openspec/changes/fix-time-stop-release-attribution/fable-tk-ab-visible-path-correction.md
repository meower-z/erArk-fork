**裁定:撤销上一轮 `PLAN PASS`,降级保留 `CHECKPOINT PASS`;新路线 `VISIBLE PLAN PASS`(附条件);无需玩家介入。**

**1. 上一轮结论的处理**

- `PLAN PASS`(最小 `[4114]` A/B)**撤销**。其关键前提——97 号档直接释放会产生同步可见经验行——已被源码核对证伪(`shoot_position_body=-1` 时 effect 527 只排入二段行为,同步 `change_data` 无经验行)。前提失效,结论作废,不因一致性保留。
- `CHECKPOINT PASS` **降级保留**。97 号档仍能作的证据:正常 UI 可达"仅一个 V 延迟高潮计数"的时停 H 状态,来源与哈希真实,证明路线前半段可行。不能作的证据:任何"玩家可见归属差异"的 A/B 起点。它不是伪造或污染,只是不充分——这个区分你们已正确做出,予以确认。

**2. 新路线裁定:`VISIBLE PLAN PASS`(附条件)**

因果链完整:唯一 V 延迟计数保证 `orgasm_settle()` 释放路径触发;正常射精面板产生的 `shoot_position_body=2` 走进经验 111 分支;`time_stop_release=True` 转成经验 78,得到同步可见行 `无意识绝顶经验 +1`;该行的分组归属正是 effect 527 的精确边界。全程正常 UI,无 debug、无手改存档。条件:见第 3、4 条的探索与门槛要求。

**3. 允许的最小单侧探索:批准你们提议的形式**
