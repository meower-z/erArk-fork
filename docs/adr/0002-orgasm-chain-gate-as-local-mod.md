# ADR-0002: 高潮后行为阻断按"玩家点击"作用域,以本地 mod 交付

日期:2026-07-18(自 openspec `per-click-orgasm-chain-gate` 蒸馏)

## 背景

NPC 实际高潮释放后仍在同一次玩家点击内继续生成自主行为(尤其群交 type-1/type-2 两个 AI 生成入口,见 `CONTEXT.md` 词汇表),观感割裂。向上游提交的修复(PR #226"绝顶后不再行动")被拒。

## 决策

- 作用域选**最外层玩家点击**,不建立按游戏分钟倒计时的恢复状态:记录随点击创建、嵌套更新复用、点击结束(含异常)清理,存档反序列化后必须重置,旧档缺字段视为未释放。
- 只登记 NPC 的**实际释放**(完整事务结算后幂等登记);成功寸止、时停蓄积、玩家自身高潮不登记。
- 阻断只作用于自主行为**生成**入口;被动受刺激、数值/二段结算、完成集合收敛全部照常,不许造成主循环挂起。
- 上游拒收后落地为 `mod/local_orgasm_chain_gate_fix`(wrapper 检测 `plural_orgasm_*`),不再尝试推上游。

## 后果

长点击(如 60 分钟)中释放过的 NPC 该点击内保持安静;新点击立即恢复。风险集中在"登记时机=事务完整结算后",过早登记会吞掉派生效果。
