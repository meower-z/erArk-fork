# ADR-0004: 存档跨 OS 路径规范化只作用于枚举的结构化房间地址字段

日期:2026-07(自 openspec `save-portability` 蒸馏)。状态:该行为已随上游 PR #207 合并,由上游核心实现;本 ADR 保留的是其作用域决策。

## 决策

读档时在版本迁移与地图对账**之前**,把已知结构化房间地址字段(场景/地图字典键、`scene_path`/`map_path`、角色 `dormitory`/`pre_dormitory`、宿管目标房间、空气催眠位、设施损坏键、维护地点)里的异 OS 分隔符转成当前平台格式。**仅限这张枚举清单**:对话、描述、名字等普通文本即使含 `/` 或 `\` 也一律不改写;字段缺失时跳过,不发明字段、不阻止读档。

## 后果

Windows↔Linux 互带存档时角色/设施与地图位置保持关联。用白名单而非"看起来像路径就转"的启发式,避免误伤普通文本——新增结构化地址字段时必须记得扩清单。
