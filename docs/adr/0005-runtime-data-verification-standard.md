# ADR-0005: 指令前提正交化 + "源 CSV 不算验收证据"标准

日期:2026-07(自 openspec `time-stop-unconscious-h-entry` 蒸馏)。状态:第 1 条的 5052 前提修正已随上游 PR #211 合并;第 2 条是持续有效的通用工作标准。

## 决策

1. **前提正交化**:无意识 H 指令(5052)的可用性按独立条件组合判断——目标有任意非零 `unconscious_h` 即满足无意识要求;临盆/产后各自独立拦截,**不用**"合作或监禁"这类复合前提做代理(监禁不能绕开妊娠拦截)。修改指令前提时保持各 gate 正交,新写复合前提前先问能否拆成独立条件。
2. **runtime 数据验收标准**:改了 `data/csv/*.csv` 不算完成——必须重建并对 `data/data.json` 做结构化读取验证(确认新前提在、旧复合前提不在),同时保证受保护的 PO 文件(`data/po/` 下由人工翻译维护的本地化文件,构建脚本可能触碰它们)字节不变——防止一次数据重建顺手改写翻译成果。仅检查源 CSV 不是验收证据。

## 后果

第 2 条是通用工作标准,适用于一切 CSV→JSON 构建链上的改动,不只 5052。
